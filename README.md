# WeatherFinder Weather Data

Public, generated forecast data consumed by WeatherFinder.

## Finding the data

Open `manifest.json` in this repository first. It lists the latest immutable JSON assets and their SHA-256 checksums. The forecast files themselves are stored under this repository's **Releases** page so frequent updates do not inflate the Git history.

The schema-version-2 manifest is organized as:

- `overview`: small worldwide country-card forecasts for fast startup.
- `continents`: country codes grouped by continent.
- `countries`: direct 10-day and optional days 11-16 downloads for each country.
- `core` and `extension`: full worldwide files retained for compatibility.

WeatherFinder can show the overview first, fetch only the selected country's file, and cache country files independently. The days 11-16 extension is downloaded only when available and needed.

This repository is generated by the private WeatherFinder Data Fetcher. Do not edit forecast data manually.

Weather data attribution: Open-Meteo and MET Norway.
