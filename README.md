# WeatherFinder Weather Data

Public, machine-readable forecast snapshots generated by the private WeatherFinder Data Fetcher.

WeatherFinder reads manifest.json, validates its schema and location-set hash, and downloads fresh release assets when available. If the feed is stale, incomplete, unavailable, or incompatible, the mobile app falls back to its existing weather-provider flow.

## Snapshot layout

- **Core:** forecast days 1–10.
- **Extension:** forecast days 11–16.
- Each part has an independent generation timestamp and checksum.
- Release filenames are immutable and timestamped.
- The manifest is updated only after an asset upload completes successfully.

## Attribution

Forecast data are derived from Open-Meteo and, when required for missing core locations, MET Norway. Data are normalized and modified for WeatherFinder. Provider attribution and licensing remain applicable:

- [Open-Meteo](https://open-meteo.com/) — CC BY 4.0 data.
- [MET Norway Weather API](https://api.met.no/) — CC BY 4.0 open data and provider terms.

This repository contains generated data only. Publisher source code is maintained separately in a private repository.
